## How submissions work

Uploads and links are sent to a small Google Apps Script (`apps-script/Code.gs`) that saves each file into the member's folder in the group's Google Drive and logs the date and time (Philippine time) in a Google Sheet and `SUBMISSIONS_LOG.md`.
